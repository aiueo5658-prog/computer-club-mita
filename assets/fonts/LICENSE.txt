Web fonts in this folder / このフォルダの Web フォント
==========================================================

These files are subsets (only the characters used on this site) of the
fonts below, converted to WOFF2 by tools/subset-fonts.py. Because they are
Modified Versions under the SIL Open Font License 1.1, they are renamed and
do not use the Reserved Font Names of the originals.

サイトで使う文字だけを残して WOFF2 にしたものです（tools/subset-fonts.py）。
SIL Open Font License 1.1 の「改変版」にあたるため、元の予約フォント名は使わず
名前を付け替えています。元フォントの著作権表示とライセンスは以下のとおりです。
