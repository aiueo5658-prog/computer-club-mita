## 1. 座標系

図の**内寸**を実寸に割り当てる。図は 955px × 1140px、
教室の実寸を **幅 7.5m × 奥行 9.0m** と仮定すると
127.3px/m と 126.7px/m でほぼ一致したので、この仮定を採用する。

- **スケール: 約 127px = 1m**
- 原点 (0,0) = 図の左上の内側の角
- `x` = 右方向（0 → 7.5m）
- `z` = 下方向（0 → 9.0m）※three.js では平面の奥行き
- 変換式: `x = (px - 405) / 127`, `z = (py - 105) / 127`

> ⚠️ 7.5m × 9.0m は図の縦横比から逆算した**推定値**。
> 実際の教室の寸法が分かれば、その値で全体をスケールし直すこと。

## 5. 順路

図の太い破線（青）とシアンの破線をつないだ一本道。

1. **入口**（左壁 z≈7.3m）から入る
2. 下側を右へ（z≈6.65m のライン）
3. 右寄り x≈5.59m を上へ
4. z≈2.4m のラインを通って上段へ
5. 上段を右回りに **3Dモデル展示 → PC展示** と回る
6. **出口**（左壁 z≈1.15m）から出る

ゾーンの並び（順路順）:
`入口 → VTuber体験 → スタジオ体験 → PC展示(中段) → Vocaloid体験 → 3Dモデル展示 → PC展示(上段) → 出口`
